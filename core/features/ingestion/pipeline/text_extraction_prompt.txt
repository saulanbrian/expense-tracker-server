### Output Schema
Return ONLY a JSON object matching this exact structure:

### Step 1: Quality Assessment
Before extracting, assess the OCR text quality:
- Is the text readable and complete, or is it garbled/truncated?
- Are critical fields (vendor, amounts, dates) present and clear?
- Does the text appear to be from a scanned document with poor OCR quality?

If the text is poor quality, garbled, incomplete, or appears to need vision processing:
- Set "needs_vision" to true
- Set "reason" to explain why (e.g., "Text appears garbled", "Missing critical fields", "Likely scanned document")
- Set "is_financial_billing" to false
- Return null for "document" and "document_line_items"

### Step 2: Document Classification
If the text quality is good:
- Determine if it is a financial billing document (e.g., invoice, receipt, utility bill, statement of account, purchase order)
- If NOT a billing document, set "is_financial_billing" to false and return null for document/line items
- If IS a billing document, proceed with extraction

### Step 3: Data Extraction (Only if is_financial_billing is True)
1. Use the "layout_description" field to describe how the data is organized in the text
2. "document.vendor_name", "document.currency", and "document.total_amount" are highly critical. If they cannot be found, return null.
3. For "document.currency", always output standard 3-letter ISO codes (e.g., USD, EUR, GBP, PHP).

### Date Rules
- ALL dates MUST be in YYYY-MM-DD format (e.g., "2024-10-26")
- If you see 10/26/2024 or 26/10/2024, convert to 2024-10-26
- If you see October 26, 2024, convert to 2024-10-26
- Return null for missing or unreadable dates

4. For "document_line_items":
   - "description" and "total_price" are REQUIRED for every line item
   - "page_number" is REQUIRED (default to 1 if not specified)
   - If "quantity" is missing but a price exists, default it to 1
   - If "unit_price" is missing, default it to equal "total_price"
5. "gl_code": Predict a standard corporate accounting category code (e.g., SOFTWARE_SAAS, OFFICE_SUPPLIES, TRAVEL_MEALS, HARDWARE_EQUIPMENT, UTILITIES, UNCLASSIFIED)

### Mathematical Integrity:
- The sum of all item "total_price" values MUST equal the parent "subtotal"
- The "subtotal" + "tax_amount" MUST equal the parent "total_amount"
